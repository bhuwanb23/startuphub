# Final Founder Sidebar

For the actual UI, **don't show every sub-page in the sidebar simultaneously**. Keep the primary sidebar around **15–18 items**:

```text
┌──────────────────────────────┐
│ StartupHub                   │
│                              │
│ 🏠 Dashboard                 │
│                              │
│ 🚀 My Startup                │
│ 💡 Idea & Validation         │
│ 🏢 Incubation                │
│ 👥 Mentors                   │
│ ⚖️ IPR & Legal               │
│ 🧩 Resources                 │
│ 🛠 Product                   │
│ 📊 Market Intelligence       │
│ 👤 Customers                 │
│ 💰 Funding                   │
│ 💳 Finance                   │
│ 📈 Growth                    │
│ 🤝 Partnerships              │
│ 🎯 Opportunities             │
│                              │
│ ✨ Startup Copilot           │
│ 📁 Documents                 │
│ 💬 Messages                 │
│ 🔔 Notifications             │
│ 📅 Calendar                  │
│                              │
│ ───────────────────────────  │
│ ⚙ Settings                  │
│ ❓ Help & Support             │
└──────────────────────────────┘
```

### Important design principle

**Don't create a sidebar item for every feature.** For example, `Patent Management`, `Trademark Management`, `Copyright Management`, and `IP Portfolio` belong under **IPR & Legal**. Likewise, `Revenue`, `Expenses`, `Cash Flow`, `Burn Rate`, and `Runway` belong under **Finance**.

This gives you a **professional application architecture rather than a feature dump**, while still preserving every feature you listed and giving each one a clear page/sub-page destination.
