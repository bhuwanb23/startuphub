# 5. Investor / VC / Angel — Complete Logged-in Structure

For the investor workspace, the architecture should be significantly more sophisticated than the other roles because this is essentially a **deal intelligence + due diligence + deal execution + portfolio management system**.

Core flow:

**Discover → Match → Evaluate → Due Diligence → Deal → Invest → Monitor → Analyze**

### The important distinction

The investor's workspace should not just be a **startup directory with an investment button**.

It should function as a complete **investment operating system**:

**Deal Sourcing + AI Matching + Investment Intelligence + Due Diligence + Deal Execution + Portfolio Intelligence.**

That is what makes the Investor module substantially valuable within the larger StartupHub ecosystem.
