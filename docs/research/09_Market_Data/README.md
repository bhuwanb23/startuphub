## The rule

> **Do not start from "we want ₹100 crore market."**
> **Start from "how many institutions can we realistically acquire?"**

Phase 7 `todo.md` builds SOM from actual acquisition capacity — Year 1 → 5 institutions, Year 2 → 15, Year 3 → 40–50 — and then computes ARR. That is the correct order of operations and Phase 0 supports it.
