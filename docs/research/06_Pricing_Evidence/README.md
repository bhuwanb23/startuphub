## The three rules for this folder

1. **Never present a competitor's asking price as evidence of what an institution would pay.** They are different quantities.
2. **`todo.md` carries an assumed ₹1.2 lakh/year with no source. It is wrong in the direction that matters** — NestLens Orbit publishes ₹75,000/yr all-in. → `Decision_Log` `D-006`
3. **Free-tier anchors set the floor, not the market.** Trello at ₹54k/yr for 10 users sits inside the band and has no institutional feature set at all. The real price fight is over the ₹0 incumbent — Excel, Sheets, WhatsApp — and that is a labour-substitution argument, not a feature argument.
