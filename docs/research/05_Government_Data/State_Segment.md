# Segment G9 — the State Startup Nodal Department

**Phase 6, added to Phase 4 segmentation. Built 2026-10-19.**

---

## State Startup Nodal Department / Mission

> The only buyer found in this project with a budget, a national scorecard and state-wide scope. Scored annually by the union on an active State Startup Policy, a Nodal Officer, a Nodal Department, a Dedicated Team, and the number of startups availing institutional support. That last item IS a venture register.

---

## Why this is a different buyer, not another segment

| | Institution (G1–G8) | State Nodal Dept (G9) |
|---|---|---|
| **Who is scored** | nobody | the union, annually, publicly |
| **What it must evidence** | IIC activity (soft quarterly score) | a startup count supporting institutional support (hard, documentary) |
| **Budget** | none documented in 8 procurement instruments | policy-linked funds |
| **Scope** | one campus | whole state |
| **Incumbent** | none found | an existing portal, already live |
| **Deal shape** | a licence | a portal replacement |

## What they need

(a venture register they can evidence to the union; department-wise support counts for their SRF submission; incubator and mentor lists; grievance tracking with a 30-day resolution clock)

The first of those is the wedge: **a state cannot evidence a startup count it cannot produce.** That is structurally the same defect as the NIRF DPIIT join we measured in Phase 3A — one level up, and with a funded buyer attached.

---

## The forcing event

- **SRF evaluation cycle; scores published annually in January**

This is a **hard, annual, public** deadline — the strongest forcing event found anywhere in this project, and materially stronger than the NIRF 31 January submission that drives G3.

## The caveat that matters

> One portal contract wins or loses an entire state. This is a different motion from institutional selling: fewer, larger, slower deals with a different procurement path. It is NOT a volume segment.
