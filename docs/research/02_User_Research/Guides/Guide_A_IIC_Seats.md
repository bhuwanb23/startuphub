**Role class A · recruitment priority 1 · Phase 2 refs: A-03, A-01, A-10**

Built 2026-10-19 by `build/build_phase3b.py`. 8 questions. 30–40 minutes.

---

## Why this role, and why now

Phase 1 shows this is one part-time academic doing the work for the whole institution (SSCET: 40 IIC members, 30 ambassadors, 2 mentors; NIT Calicut: 29 mentors against 155 ideas). They are simultaneously the user, the evidence source, and the only plausible internal champion. They are also the person who already discovered the DPIIT join problem in practice.

## Questions

### 1. Walk me through the last NIRF innovation submission you filed, start to finish. Where did you begin?

- **Bank:** Q1 — Current workflow
- **If the answer is thin, ask:** What was open on your screen? What was next to it?
- **Tests:** `P-A10 / F-DPIIT-JOIN`
- **This answer would show:** If they begin from a single system that already holds a venture list, the 'no venture register' gap is smaller than Phase 1 concluded.

### 2. In that same submission, you had to record a TRL for each innovation. Where did the DPIIT registration number come from?

- **Bank:** Q1 — Current workflow
- **If the answer is thin, ask:** Did you ask the founder? Look it up on the DPIIT portal? Did someone else give you a list?
- **Tests:** `OQ-32`
- **This answer would show:** Resolves OQ-32. Determines whether the product is a better spreadsheet or a workflow carrier.

### 3. When you could not find a DPIIT number for a startup, what did you actually type into the cell?

- **Bank:** Q2 — Pain
- **If the answer is thin, ask:** Did you leave it blank, put a placeholder, or drop the row entirely?
- **Tests:** `OQ-33 / F-DPIIT-JOIN`
- **This answer would show:** Explains the DIPP0000 placeholders in 3 real forms.

### 4. How long did that whole submission take you, and how much of it was re-work?

- **Bank:** Q2 — Pain
- **If the answer is thin, ask:** Roughly how many hours? Was there a point where you had to redo rows?
- **Tests:** `P-A08 / P-A02`
- **This answer would show:** P-A08 grades hand-assembly DOCUMENTED; this tests whether it is felt as rework.

### 5. What do you use between cycles to keep track of these startups - before the form asks you to?

- **Bank:** Q3 — Existing tools
- **If the answer is thin, ask:** Excel? Google Sheets? WhatsApp groups? A register someone else maintains?
- **Tests:** `P-A10 / P-A01`
- **This answer would show:** P-A01 asks whether institutions keep a venture register at all.

### 6. Is that spreadsheet yours, or does it come from someone else in the institute?

- **Bank:** Q3 — Existing tools
- **If the answer is thin, ask:** Who else edits it? Does the Registrar see it?
- **Tests:** `OQ-28 / P-A04`
- **This answer would show:** Tests whether Convener and Incubation Manager are one person, and whether data flows upward.

### 7. When ARIIA asks for a similar count a few weeks later, do you reuse the same list?

- **Bank:** Q1 — Current workflow
- **If the answer is thin, ask:** Have you ever compared the two numbers?
- **Tests:** `OQ-34 / F-ARIYA-AY`
- **This answer would show:** If they reuse and reconcile, the duplication problem is weaker than claimed.

### 8. You asked for Rs 1.2 lakh for something. Where did that number come from?

- **Bank:** Q5 — Value
- **If the answer is thin, ask:** Did you compare it to something you already spend, or was it a guess?
- **Tests:** `D-007 / pricing ledger`
- **This answer would show:** Tests whether the price band is anchored to anything real.

## The artefact ask

> *"Would you be willing to share a screenshot or a blank version of what you filled in last time? Blank out any names. I just want to see the shape of it — which columns you had open, where the data came from."*

Optional, at the end. Declining is fine and is not a signal about the institution.

> *Note:* this asks permission to receive a document. It is a consent request, not a validation question — it hypothesises nothing about the future, which is why it is allowed to be phrased this way when the structured questions are not.
