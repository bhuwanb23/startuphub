## Questions

### 1. Does the institute's official record of startups come to you, or do you go and get it?

- **Bank:** Q1 — Current workflow
- **If the answer is thin, ask:** Who compiles it? How often? In what format?
- **Tests:** `P-A10 / OQ-29`
- **This answer would show:** P-A10 documents consolidation by hand; this tests who owns the output.

### 2. Last time an annual report or NIRF filing needed innovation numbers, what did you do with them?

- **Bank:** Q1 — Current workflow
- **If the answer is thin, ask:** Did you chase anyone? Did you get them once or repeatedly?
- **Tests:** `P-A04 / P-A08`
- **This answer would show:** P-A04 says one coordinator is the integration point for several problems.

### 3. Which budget head would a Rs 1-2 lakh annual software purchase come from?

- **Bank:** Q4 — Buying
- **If the answer is thin, ask:** Have you approved anything in this range? Under which head?
- **Tests:** `OQ-29`
- **This answer would show:** OQ-29 asks exactly this. Phase 0 has no answer.

### 4. Walk me through the last software purchase you approved. What was the route?

- **Bank:** Q4 — Buying
- **If the answer is thin, ask:** Was there a committee? GeM? Direct purchase? How many weeks?
- **Tests:** `Phase 2 procurement ladders / OQ-27`
- **This answer would show:** Tests whether the Rs 50K-Rs 10L committee spread is reality.

### 5. What would make you NOT approve this?

- **Bank:** Q4 — Buying
- **If the answer is thin, ask:** Is there a security questionnaire? A data-localisation clause?
- **Tests:** `OQ-30 / EcoSync SOC2 disqualification`
- **This answer would show:** OQ-30 asks whether IT Admin has a veto.

### 6. Is there an existing system that already holds this, and why wasn't it used?

- **Bank:** Q3 — Existing tools
- **If the answer is thin, ask:** ERP? Student information system? Existing software renewal?
- **Tests:** `Phase 0 free-incumbent assumption`
- **This answer would show:** If a paid system already exists, the incumbent is not free.

## The artefact ask

> *"Would you be willing to share a screenshot or a blank version of what you filled in last time? Blank out any names. I just want to see the shape of it — which columns you had open, where the data came from."*

Optional, at the end. Declining is fine and is not a signal about the institution.

> *Note:* this asks permission to receive a document. It is a consent request, not a validation question — it hypothesises nothing about the future, which is why it is allowed to be phrased this way when the structured questions are not.
