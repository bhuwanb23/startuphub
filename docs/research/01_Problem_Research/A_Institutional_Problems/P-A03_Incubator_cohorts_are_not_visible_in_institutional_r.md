# P-A03 - Incubator cohorts are not visible in institutional reporting

**Evidence grade:** `HYPOTHESIS` - Structurally implied but NOT evidenced. Requires Phase 3 interviews.

**Severity:** `MEDIUM` - Recurring friction that slows work but is survivable.

**Corpus documents cited:** `IIC-001`, `IIC-016`, `IIC-012`

> **Not an observed user problem.** Phase 3 user interviews have not been conducted. This is documentary analysis of what institutions publish about themselves. Do not present it to a third party as an observed user problem.

---

## Statement

The IIC reporting schema has no cohort concept. Nothing in the 36-document corpus records which ventures entered which batch, when, or on what terms.

## Evidence

- Across 36 documents, no institution reports a cohort, batch, intake cycle or admission date. The vocabulary is uniformly ideas / prototypes / IPs / startups.
- Incubation appears only as infrastructure narrative - NIT Calicut's TBI incubating 115 startups and 1,500+ jobs (`IIC-001`), CMRIT's pre-incubation centre serving 25 students, 46 faculty and 5 external startups (`IIC-016`) - with no cohort structure attached.
- Scottish Church College reports a single innovation centre funded by an individual angel investor, with no intake or cohort accounting at all (`IIC-012`).

### What is still missing

MATERIAL. This is an absence-of-evidence finding, not a positive finding. The corpus contains almost no cohort data because the IIC form does not ask for any. It does NOT follow that institutions lack cohorts - only that this reporting surface cannot show them. To close: interview 3-4 incubators (TBI/AIC/ATAL-incubatee) and ask directly how they define and record a cohort. Phase 18 modelling depends on this.

## Who experiences it

Incubator managers; programme managers running cohorts for DST, Atal Innovation Mission, NIDHI-PRAYAS or state missions.

## Severity - MEDIUM

Downgraded from HIGH precisely because the evidence is an absence. Would be HIGH if a single document showed cohort data being lost.

## Frequency

Per intake cycle, for institutions running any cohort-based programme.

## Current workaround

UNKNOWN - this is the point. No workaround is visible in any retrieved document because no document discusses cohorts. Presenting a workaround here would be fabrication.

## Quantified cost

Not available. No cost data exists in this corpus for cohort management.

## Failure consequence

Cannot yet be stated. If cohorts are tracked manually, the exposure is lost institutional memory and funding-reporting errors. That is a reasoned expectation, NOT an observation.

## Potential fixer

Cohort as a first-class object with intake, terms, seats, and per-seat funding - which is also what scheme reporting requires.

## Competitive implication

Cannot be claimed yet. This is a candidate differentiator for Phase 4 segmentation, and it must not appear in any external material until Phase 3 confirms cohorts are a real managed object.
