# Section A - Ten Institutional Problems

todo.md Section A asks for evidence on ten institutional problems. This folder holds one analysis per problem, each built to the same nine fields.

## Read this first

**No user interviews have been conducted.** Phase 3 has not started. Everything here is documentary analysis of documents institutions published about themselves. This is evidence about *reporting behaviour*, which is real and useful, but it is not the same thing as evidence about what users say they struggle with. Phase 3 may revise these rankings substantially - that is the correct outcome, not a problem with the work.

## Evidence grades

| Grade | Meaning |
|---|---|
| `DOCUMENTED` | Multiple primary documents read and cited by corpus_id. |
| `SINGLE-SOURCE` | One primary document. Suggestive; must not carry a claim alone. |
| `HYPOTHESIS` | Structurally implied but NOT evidenced. Requires Phase 3 interviews. |

Distribution: 7 DOCUMENTED, 2 SINGLE-SOURCE, 1 HYPOTHESIS.

## What is strongest and what is weakest

**Strongest.** `P-A07` (IP deadlines and IP records) is the only CRITICAL. It is the strongest finding in Phase 1 because it is corroborated from two independent directions: peer-reviewed TTO literature on the cost of missed prosecution deadlines, and 36 institutional reports in which no deadline field appears. It also independently confirms the Phase 0 thesis that no competitor has an IPR module.

**Weakest, and deliberately labelled.** `P-A03` (incubator cohorts) is graded HYPOTHESIS and `P-A05` (mentorship) is SINGLE-SOURCE. Both describe plausible institutional problems that this corpus **cannot** evidence. P-A03 in particular is an absence-of-evidence finding: the IIC form does not ask about cohorts, so their absence from the reports proves nothing about whether institutions manage them.

**The gap that matters most.** `P-A10` shows institutional data is consolidated manually across departments, but no retrieved document reveals any institution's *internal* tooling. We have only ever seen the export. Until Phase 3 establishes what sits upstream - Excel, an ERP, or paper - todo.md Section B's "Excel dependency" claims remain unevidenced and must not be asserted in any external material.
