## The headline

Segment sizes span **three orders of magnitude**:

```
1,289        universities
8,489        AICTE technical institutions (⚠️ Tier 2, PRS)
48,246       colleges
64,756       all HEIs
─────────────────────────────────────────────
~103         AIC + ACIC centres
~160–175     DST TBIs
517+         MeitY Startup Hub incubators
⚠️ 6,400+    IICs (2022 — stale)
```

**This spread is why `todo.md` Phase 0's request to freeze a beachhead was the right instruction to defer.** Choosing a denominator before this survey existed would have produced a TAM that was wrong by two orders of magnitude.
