# Quote Vault - Phase 1 Institutional Evidence

**Verbatim only.** Every string below was read in the source document named in its row. Nothing here is paraphrased, summarised or reconstructed.

## How to use this file

- `tier` follows the repository standard in `00_Research_Index/README.md` section 3.
- `extraction_method = pdf_text_layer` means the string came from a machine-extracted text layer rather than a visually confirmed page. PDF text layers scramble ligatures, bullet glyphs and Devanagari conjuncts.
- **Every quote is flagged `recheck_before_external_use = TRUE`.** Re-verify against the original PDF page before any of this appears in a pitch, deck or external document.
- To quote one of these, find `doc_id` in `../01_Problem_Research/01_Evidence_Corpus/` or in `_exports/phase1/csv/iic_reports_wide.csv` to get the full document record.
