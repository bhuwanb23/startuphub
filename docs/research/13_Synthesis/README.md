## On narrowing

`Decision_Log` `D-002` deliberately did **not** freeze the beachhead customer in Phase 0, per direction. All segments — universities, engineering colleges, IIC/TBI institutions, standalone incubators, startups — were researched in parallel.

That was the right call, because Phase 0 surfaced segment sizes spanning **three orders of magnitude** (1,289 universities vs 48,246 colleges vs 160+ DST TBIs) and revealed that the two most obvious beachheads are both compromised:

- **Universities broadly** — count is unknown (`OQ-01`), and the 204-institution NIRF cohort is far more reachable than the full 1,289
- **Standalone incubators / TBIs** — the highest-ARPU segment, and the one Orbit, IncubatX and EcoSync already target head-on
