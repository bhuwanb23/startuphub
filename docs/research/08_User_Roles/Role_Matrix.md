## Reading the matrix

- **Uses is well evidenced; pays is not.** That gradient is the finding, not a gap in the data collection.
- **`pays` is `HYPOTHESIS` for 18 of 25 roles.** Only VC/Director, Dean/Innovation Head, Registrar/Dean (ICSR) and Finance Officer have documented budget authority, and every one of those citations is a procurement instrument.
- **Class A has a high `uses` score and a zero `pays` score.** The mandated offices run the system without funding it.
