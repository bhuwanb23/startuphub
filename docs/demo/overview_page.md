Then, after these are visually established, we move to **Founder Dashboard → Incubator Dashboard → Investor Dashboard → Mentor Dashboard → IPR Dashboard → etc.**

That keeps the demo progression logical: **public ecosystem first, authentication second, role-specific product third.**
